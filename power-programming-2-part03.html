02

Data types and conversion

أنواع البيانات والتحويل بينها

int is an integer, float is a decimal number, str is text, and bool is True or False. Numbers read as text must be converted before arithmetic.

يمثل int العدد الصحيح، وfloat العدد العشري، وstr النص، وbool الحالة المنطقية. لا تجري عمليات حسابية على النصوص دون تحويلها.

MATLAB → Python | المقارنةMATLAB: str2double('12.5') ; Python: float('12.5')
Python · Kaggle · Unit 02
voltage_text = '12.5'
voltage = float(voltage_text)
current = 2
active = True
power = voltage * current
print(type(voltage).__name__)
print(active, power)

Line-by-line explanation | شرح كل سطر

  1. L1
    Create a string containing the characters 12.5.ننشىء نصا يتكون من المحارف 12.5.
  2. L2
    Convert the text into a decimal (float) number.نحوّل النص إلى عدد عشري باستخدام float.
  3. L3
    Set the current to 2 A (integer).نجعل قيمة التيار 2 أمبير من النوع الصحيح.
  4. L4
    Record a Boolean status using True.نسجل حالة منطقية بقيمة True.
  5. L5
    Multiply numerical voltage and current.نضرب الجهد العددي بالتيار.
  6. L6
    type(voltage) returns the type object float. The attribute .__name__ extracts that type’s name as the text float; print displays it.تعيد type(voltage) نوع المتغير وهو float. ثم تقرأ الخاصية .__name__ اسم هذا النوع كنص float وتعرضه print.
  7. L7
    Display the state and power of 25 W.نعرض الحالة والاستطاعة الناتجة 25 واط.

.__name__ explained | شرح .__name__

Consider voltage = 12.5. The expression type(voltage) finds its type (the float class). In contrast, type(voltage).__name__ accesses the name attribute of that class and returns the string 'float'.

The dot . means “access an attribute”. In __name__, there are two underscores before and two after name. Such a double-underscore name is called a dunder name. It is not the name of our variable, and it does not change its value.

إذا كان voltage = 12.5، فإن type(voltage) يحدد نوع القيمة وهو الصنف float. أما type(voltage).__name__ فيقرأ خاصية الاسم لهذا الصنف ويعيد النص 'float'.

تعني النقطة . الوصول إلى خاصية. في __name__ توجد شرطتان سفليتان قبل كلمة name وشرطتان بعدها، ويسمى هذا النمط dunder. ولا يقصد به اسم المتغير ولا يغير قيمته.

A for loop processes a known series of measurements. A while loop repeats only while its condition remains true; always make sure it can stop.

Python · Kaggle · Unit 05
loads_kw = [1.0, 1.5, 2.0, 1.5]
energy_kwh = 0
for load in loads_kw:
    energy_kwh += load * 1
print('Energy:', energy_kwh)
count = 0
while count < 2:
    print('Check', count)
    count += 1

MATLAB → Python | المقارنةMATLAB: function P = dc_power(V,I); P = V*I; end

def dc_power(voltage_v, current_a):

        raise ValueError('Use positive values')
    return voltage_v * current_a

Complex power in AC circuits

الاستطاعة العقدية في دارات التيار المتناوب

Python uses j for the imaginary unit. For RMS phasors and passive sign convention, complex power is S = V × conjugate(I), with real part P and imaginary part Q.

تستخدم Python الحرف j للوحدة التخيلية. عند استعمال الفازورات بالقيم الفعالة واتفاقية الحمل تكون الاستطاعة العقدية S = V × مرافق(I)، وجزؤها الحقيقي P والتخيلي Q.

MATLAB → Python | المقارنةMATLAB: S = V * conj(I); Python: S = V * I.conjugate()
Python · Kaggle · Unit 11
import cmath
voltage = 230 + 0j
current = 8 * cmath.exp(-1j * cmath.pi / 6)
s = voltage * current.conjugate()
p_w = s.real
q_var = s.imag
print(round(p_w), 'W')
print(round(q_var), 'var')

Mini-project: PV, load and battery

المشروع المصغر: الطاقة الشمسية والحمل والبطارية

A first energy-balance simulation with one-hour steps, a 90% one-way charge/discharge efficiency, no export, and no power limit. It teaches algorithms, not a complete real-world design.

محاكاة أولية لميزان الطاقة بخطوة زمنية قدرها ساعة، وكفاءة شحن وتفريغ أحادية الاتجاه 90%، دون تصدير أو حد للاستطاعة. الهدف تعلم الخوارزمية وليس اعتماد تصميم هندسي جاهز.

MATLAB → Python | المقارنةMATLAB: use a for loop, if/else, and vector indexing 1...N. Python indexes 0...N-1.
Python · Kaggle · Unit 12
load_kw = [2, 3, 2, 1]
pv_kw = [0, 4, 3, 0]
soc = 2.0  # stored kWh
capacity = 4.0
eta = 0.90
for hour in range(len(load_kw)):
    net_kw = pv_kw[hour] - load_kw[hour]
    if net_kw >= 0:
        charge_kw = min(net_kw, (capacity - soc) / eta)
        soc += charge_kw * eta
        grid_import = 0.0
    else:
        discharge_kw = min(-net_kw, soc * eta)
        soc -= discharge_kw / eta
        grid_import = -net_kw - discharge_kw
    print(hour, round(soc, 2), round(grid_import, 2))
