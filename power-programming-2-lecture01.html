1. What changes—and what does not? | ما الذي يتغير وما الذي لا يتغير؟

Engineering problem → equations → algorithm → code → result → engineering interpretation

MATLAB and Python are tools. Ohm's law, complex power and network equations do not change when the language changes.

MATLAB وPython أداتان. قانون أوم والاستطاعة العقدية ومعادلات الشبكة لا تتغير بتغير لغة البرمجة. الذي يتغير أساساً هو طريقة كتابة التعليمات والمكتبات وبيئة التنفيذ.

2A. What does “library” mean? | ماذا تعني كلمة «مكتبة»؟

A library is a collection of ready-made programming tools. Think of an engineering toolbox: instead of writing every numerical method yourself, you call a suitable tool. Python is the language; NumPy is a numerical library; Matplotlib is a plotting library; Kaggle is where we run the code.
المكتبة هي مجموعة أدوات برمجية جاهزة، مثل صندوق أدوات المهندس. بدلا من كتابة كل عملية عددية بنفسك، تستعمل أداة مناسبة جاهزة. Python هي اللغة، وNumPy مكتبة حسابات عددية، وMatplotlib مكتبة رسوم، أما Kaggle فهي منصة تشغيل الكود.
import numpy as np: load NumPy and give it the short name np. np.array(...) calls the array tool inside NumPy. The dot means “use a tool belonging to this library”.
import numpy as np: استدعاء NumPy وإعطاؤها الاسم المختصر np. التعليمة np.array(...) تستدعي أداة تكوين مصفوفة داخل المكتبة. النقطة تعني استخدام أداة تابعة لهذه المكتبة.
import matplotlib.pyplot as plt: load the plotting module and use plt as its short name. These aliases are conventions, not new programming languages.
import matplotlib.pyplot as plt: استدعاء وحدة الرسم وإعطاؤها الاسم المختصر plt. هذه الاختصارات أسماء متعارف عليها وليست لغات برمجة جديدة.

3. What is Kaggle Notebook? | ما هو Kaggle Notebook؟

A Notebook combines executable code, output, text and figures in one document. Kaggle runs the code in the cloud, so the phone acts mainly as the interface.

الـNotebook يجمع الكود القابل للتنفيذ والنتائج والنصوص والأشكال في وثيقة واحدة. ينفذ Kaggle الكود على بيئة سحابية، ولذلك يعمل الهاتف أساساً كواجهة للكتابة والتشغيل ومشاهدة النتائج.

Code cell | خلية Code: executable Python.   Markdown cell | خلية Markdown: explanation, equations and notes.

Run order matters | ترتيب التشغيل مهم

A Code cell is one editable block of instructions; output appears underneath. A Markdown cell explains the work and does not execute Python. Cells share memory during a running session. Run definitions before calculations. After restarting, run the required cells from top to bottom.
خلية Code كتلة قابلة للتعديل تحتوي التعليمات، وتظهر نتائجها تحتها. خلية Markdown تشرح العمل ولا تنفذ Python. تتشارك الخلايا الذاكرة ضمن الجلسة الجارية. شغل تعريف المتغيرات قبل الحسابات، وبعد إعادة التشغيل نفذ الخلايا المطلوبة من الأعلى إلى الأسفل.

3B. First Python program: DC power | البرنامج الأول: استطاعة حمل مستمر

Model: a DC load has voltage 12 V and current 2 A. Predict the power by hand, then run the same calculation on Kaggle.

P = U × I = 12 × 2 = 24 W
voltage = 12
current = 2

current = 2

power = voltage * current

اطبع النص والقيمة والوحدة؛ تفصل مسافات بين العناصر.

7A. Hand check before trusting code | تحقق يدوي قبل الوثوق بالكود

For R=30 Ω and X=15 Ω:

|Z| = √(R²+X²) = √(30²+15²) = 33.54 Ω
|I| = V/|Z| = 20000/33.54 ≈ 596.3 A

The impedance angle is tan⁻¹(15/30)=26.565°, therefore with V at 0°, the current angle is approximately −26.565°.
