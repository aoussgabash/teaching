1. What changes—and what does not? | ما الذي يتغير وما الذي لا يتغير؟

Engineering problem → equations → algorithm → code → result → engineering interpretation

MATLAB and Python are tools. Ohm's law, complex power and network equations do not change when the language changes.

MATLAB وPython أداتان. قانون أوم والاستطاعة العقدية ومعادلات الشبكة لا تتغير بتغير لغة البرمجة. الذي يتغير أساساً هو طريقة كتابة التعليمات والمكتبات وبيئة التنفيذ.

2. What is Python? | ما هي Python؟

Python is a general-purpose programming language. For numerical engineering work we will mainly use NumPy for numerical arrays and mathematics, Matplotlib for plotting, and later Pandas for tabular/time-series data.

Python لغة برمجة عامة. في التطبيقات الهندسية العددية سنستخدم بصورة أساسية NumPy للمصفوفات والحسابات الرياضية، وMatplotlib للرسم، ولاحقاً Pandas للبيانات الجدولية والسلاسل الزمنية.

3. What is Kaggle Notebook? | ما هو Kaggle Notebook؟

A Notebook combines executable code, output, text and figures in one document. Kaggle runs the code in the cloud, so the phone acts mainly as the interface.

الـNotebook يجمع الكود القابل للتنفيذ والنتائج والنصوص والأشكال في وثيقة واحدة. ينفذ Kaggle الكود على بيئة سحابية، ولذلك يعمل الهاتف أساساً كواجهة للكتابة والتشغيل ومشاهدة النتائج.

MATLAB experience makes most operators familiar, but students should explicitly distinguish arithmetic, comparison and element-wise numerical operations before later power-system calculations.

6B. Indexing: MATLAB versus Python | الفهرسة: MATLAB مقابل Python

MATLAB indexing starts at 1, while Python indexing starts at 0. This small difference causes many mistakes when students first move between the two languages.

تبدأ فهرسة MATLAB من 1، بينما تبدأ فهرسة Python من 0. هذا الفرق الصغير سبب شائع للأخطاء عند الانتقال لأول مرة بين اللغتين.
P = np.array([5, 10, 20, 15])
print(P[0])   # first value = 5
print(P[2])   # third value = 20
print(P[-1])  # last value = 15
في المثال السابق تمثل P[0] العنصر الأول، وتمثل P[-1] العنصر الأخير. سنستخدم ذلك كثيراً عند قراءة بيانات الأحمال.

7. Complex numbers for power engineering | الأعداد العقدية في هندسة الطاقة

Z=R+jX     I=V/Z
V = 20e3
R = 30
X = 15
Z = R + 1j*X
I = V/Z

print("Z =", Z)
print("|I| =", abs(I))
print("angle(I) =", np.angle(I, deg=True), "deg")

Expected magnitude: about 596.3 A. The negative current angle is consistent with an inductive impedance.

المطال المتوقع للتيار يقارب 596.3 A. وإشارة زاوية التيار السالبة منطقية لأن الممانعة حثية، فيتأخر التيار عن الجهد.

7A. Hand check before trusting code | تحقق يدوي قبل الوثوق بالكود

For R=30 Ω and X=15 Ω:

|Z| = √(R²+X²) = √(30²+15²) = 33.54 Ω
|I| = V/|Z| = 20000/33.54 ≈ 596.3 A

The impedance angle is tan⁻¹(15/30)=26.565°, therefore with V at 0°, the current angle is approximately −26.565°.

عند R=30 Ω وX=15 Ω يكون مطال الممانعة 33.54 Ω، ومنه مطال التيار نحو 596.3 A. زاوية الممانعة 26.565°، لذلك عندما يكون الجهد مرجعاً عند 0° تكون زاوية التيار نحو −26.565°. هذه المقارنة اليدوية وسيلة أساسية لاكتشاف أخطاء الكود.

Predict → Run → Explain | توقّع ← شغّل ← فسّر

Without changing V, test three cases: (R,X)=(30,5), (30,15), (30,20). Before pressing Run, write your expected ordering of current magnitudes. Then verify it numerically.

دون تغيير V اختبر الحالات الثلاث: (R,X)=(30,5)، (30,15)، (30,20). قبل الضغط على Run اكتب ترتيباً متوقعاً لمقادير التيار، ثم تحقق عددياً من توقعك.
cases = [(30,5), (30,15), (30,20)]
for R, X in cases:
    I = V/(R + 1j*X)

8. First plot with Matplotlib | أول رسم باستخدام Matplotlib

X = np.arange(5, 21)
I = V / (R + 1j*X)

plt.plot(X, np.abs(I), marker="o")
plt.xlabel("Reactance X (ohm)")
plt.ylabel("Current magnitude |I| (A)")
plt.title("Load current versus reactance")
plt.grid(True)
plt.show()

Do not treat the graph as decoration: read the axes and units, describe the trend, then connect it to |I|=V/√(R²+X²).

الرسم ليس للزينة: اقرأ المحاور والوحدات، صف اتجاه المنحني، ثم اربطه بالعلاقة |I|=V/√(R²+X²).

8A. How to read an engineering graph | كيف نقرأ الرسم الهندسي؟

Every engineering plot should answer four questions: What is on the x-axis? What is on the y-axis? What are the units? What physical relationship explains the trend?

يجب أن يجيب كل رسم هندسي عن أربعة أسئلة: ماذا يمثل المحور الأفقي؟ ماذا يمثل المحور الشاقولي؟ ما الوحدات؟ وما العلاقة الفيزيائية التي تفسر اتجاه المنحني؟

Here, increasing X increases |Z| and therefore decreases |I| for fixed V and R. The graph is a visual representation of the equation, not an independent result.

هنا تؤدي زيادة X إلى زيادة |Z| وبالتالي انخفاض |I| عند ثبات V وR. لذلك فالرسم تمثيل بصري للمعادلة وليس نتيجة منفصلة عنها.

9. Errors are part of programming | الأخطاء جزء من البرمجة

Syntax error: invalid Python form. Name error: variable not defined. Logic/engineering error: code runs but the model is wrong.

Syntax error: صياغة Python غير صحيحة. Name error: استخدام متغير غير معرف. Logic/engineering error: يعمل الكود لكن النموذج أو العلاقة الهندسية خاطئة؛ وهذا النوع أخطر لأنه قد يعطي رقماً يبدو صحيحاً.
# Runs, but physically wrong:
Z = R + X
I = V * Z
