1. Computational thinking | التفكير الحاسوبي

Physical problem → Mathematical model → Algorithm → Code → Results → Engineering interpretation

البرنامج ليس الهدف. الهدف هو حل مسألة هندسية قابلة للتحقق. قبل كتابة أي سطر نحدد المدخلات، العلاقات الفيزيائية، المطلوب، الوحدات، ثم اختبار معقولية الناتج.

2. Core example: single-phase load

Let V = 20 kV and Z = 30 + j15 Ω. The current is:

I = V / Z    ;    |Z| = √(30²+15²) = 33.54 Ω    ;    |I| ≈ 596.3 A

The impedance angle is +26.565°, therefore the current angle is −26.565° when the voltage reference is 0°.

V = 20e3;
Z = 30 + 1j*15;
I = V/Z;
abs(I)
angle(I)*180/pi
هذه مراجعة لما يفترض أن الطالب تعلمه في MATLAB 1: عدد عقدي، قسمة، مطال وزاوية. الفحص الهندسي مهم: زيادة المفاعلة X ترفع |Z| ولذلك تخفض |I| عند ثبات V وR.

3. MATLAB → Python bridge

import numpy as np

V = 20e3
Z = 30 + 1j*15
I = V / Z

print(abs(I))
print(np.angle(I, deg=True))

The physics is unchanged. Only the programming language changes. NumPy provides numerical arrays, mathematical functions and engineering-friendly vector operations.

4. Parameter sweep

Study X from 5 Ω to 20 Ω while R and V remain constant.

import numpy as np
import matplotlib.pyplot as plt

V = 20e3
R = 30
X = np.arange(5, 21)
Z = R + 1j*X
I = V / Z

plt.plot(X, np.abs(I), marker='o')
plt.xlabel("Reactance X (ohm)")
plt.ylabel("Current magnitude |I| (A)")
plt.grid(True)
plt.show()
قبل تشغيل الكود يجب أن يتنبأ الطالب باتجاه المنحني. إذا أعطى البرنامج اتجاهاً مخالفاً للتوقع الفيزيائي، فلا نقبل النتيجة آلياً بل نراجع النموذج والكود والوحدات.

6. MATLAB foundations revisited | مراجعة أعمق لأساسيات MATLAB

المتغيرات والوحدات: في هندسة القدرة قد يكون الخطأ في kV مقابل V أو MW مقابل W أكبر من الخطأ البرمجي نفسه. لذلك نستخدم أسماء واضحة مثل V_kV أو نحوّل جميع القيم إلى SI قبل الحساب.

المتجهات: المتجه يسمح بدراسة مجموعة حالات تشغيل بدلاً من حالة واحدة. مثال: X=5:5:30 يمثل ست حالات للمفاعلة.

المصفوفات: ستصبح لاحقاً أساس تمثيل الشبكة وY-Bus وحل سريان الاستطاعة. لذلك نراجع الفرق بين الضرب المصفوفي والعمليات عنصر-بعنصر.

A = [1 2; 3 4];
x = [5; 6];
y = A*x;       % matrix multiplication
z = A.*A;      % element-by-element multiplication

سؤال صفّي: لماذا لا يمكن استبدال A*x دائماً بـ A.*x؟ اربط الإجابة بفكرة معادلات الشبكة.

7. From scalar calculation to engineering function | من الحساب إلى الدالة

A reusable function separates the engineering model from a specific numerical case.

function I = load_current(V,R,X)
    Z = R + 1j*X;
    I = V/Z;
end

I1 = load_current(20e3,30,15);
I2 = load_current(20e3,30,20);

الدالة مفيدة عندما تتكرر المعادلة مع أحمال أو حالات تشغيل مختلفة. لاحقاً سنبني بالطريقة نفسها دوالاً لحساب معامل القدرة، خطوط النقل، وثوابت ABCD.

8. Complex power and engineering verification | الاستطاعة العقدية والتحقق

Using RMS phasors:

S = V I* = P + jQ     ;     pf = P/|S| = cos(φ)

For V=20 kV and Z=30+j15 Ω, I≈536.7−j268.3 A. Therefore:

P ≈ 10.73 MW    ;    Q ≈ 5.37 MVAr    ;    |S| ≈ 12.0 MVA    ;    pf ≈ 0.894 lagging
S = V*conj(I);
P = real(S);
Q = imag(S);
pf = P/abs(S);

هذه النتيجة تقدم ثلاثة اختبارات: Q موجب لحمل حثي، عامل الاستطاعة أقل من الواحد، وP يجب أن يساوي تقريباً I²R. إذا لم تتحقق هذه العلاقات نبحث عن خطأ في الإشارة أو الوحدات أو استخدام المرافق العقدي.

9. Loop versus vectorization | الحلقة مقابل الحساب المتجهي

MATLAB loop:

X = 5:20;
for k = 1:length(X)
    I(k) = V/(R + 1j*X(k));
end

MATLAB vectorized form:

X = 5:20;
I = V ./ (R + 1j*X);

Python/NumPy:

X = np.arange(5,21)
I = V / (R + 1j*X)

الهدف ليس القول إن الحلقة «خطأ»، بل فهم أن مسائل الطاقة كثيراً ما تتطلب حساب عشرات أو آلاف الحالات. التفكير المتجهي يجعل العلاقة بين المعادلة الرياضية والكود أوضح.

10. Sensitivity study | دراسة الحساسية

Compare three reactances while R=30 Ω and V=20 kV:

X=5 Ω → |I|≈657.6 A   |   X=15 Ω → 596.3 A   |   X=30 Ω → 471.4 A

لا يكفي وصف المنحني بأنه «يتناقص». نربط ذلك بالمعادلة |I|=V/√(R²+X²). عندما تصبح X كبيرة مقارنةً بـR يصبح تأثيرها على المطال واضحاً، كما تزداد زاوية التأخر وينخفض عامل الاستطاعة.

11. Common mistakes | أخطاء شائعة

1) كتابة Z=R+X ونسيان j. 2) استخدام I=V×Z بدلاً من V/Z. 3) خلط قيمة RMS بالقيمة العظمى. 4) نسيان المرافق العقدي في S=VI*. 5) الخلط بين rad وdegree. 6) استخدام * بدلاً من .* أو / بدلاً من ./ في MATLAB عند التعامل مع المتجهات. 7) رسم نتائج صحيحة عددياً دون وحدات أو تفسير هندسي.

12. Worked extension: voltage waveform | مثال موسع

For a 50 Hz source with RMS voltage V=20 kV:

v(t)=√2 V sin(2πft)    ;    i(t)=√2 |I| sin(2πft+∠I)
f = 50;
t = linspace(0,0.04,1000);
v = sqrt(2)*V*sin(2*pi*f*t);
i = sqrt(2)*abs(I)*sin(2*pi*f*t + angle(I));
plot(t,v/1000,t,i/100)

ناقش لماذا تأخر التيار عن الجهد، ولماذا لا يجوز مقارنة محور الجهد بالكيلو فولت ومحور التيار بالأمبير دون توضيح المقياس.
