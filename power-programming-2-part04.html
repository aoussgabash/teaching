From equations to code | من المعادلات إلى الكود

First formulate the model on paper: identify what is known, what is unknown, which outputs are derived, what must be equal, and what may not exceed limits. Only then choose a solver. A system with zero equality-based degrees of freedom usually calls for solving equations; a system with free choices can be optimized when it has a meaningful objective and a feasible set.

01

The language of a mathematical model

لغة النموذج الرياضي: المتغيرات والبارامترات والدوال

A decision variable is chosen by the solver. A parameter is fixed input for one run; changing it defines a different scenario. A function maps inputs to outputs. A relation calculates a dependent quantity, and is not automatically an extra independent decision variable. Use meaningful names and units.

متغير القرار قيمة يختارها برنامج الحل الأمثل. البارامتر معطى ثابت أثناء عملية الحل الواحدة، وتغييره ينشئ سيناريو آخر. الدالة تربط المدخلات بالمخرجات. العلاقة تحسب كمية تابعة، ولا تعني بالضرورة إضافة متغير قرار مستقل. اختر أسماء واضحة ووحدات معلومة.

Mathematical model | النموذج الرياضي

Parameters: V = 12 V, R = 6 Ω. Derived current: I = V/R = 2 A. The model has no free choice if V and R are fixed.

البارامترات: V = 12 V وR = 6 Ω. التيار المحسوب من العلاقة I = V/R = 2 A. لا يبقى خيار حر ما دام الجهد والمقاومة ثابتين.

02

Equality, inequality and Python symbols

المساواة وعدم المساواة ورموز Python

An equality constraint imposes h(x) = 0. An inequality expresses a permitted range, e.g. P₁ ≤ P₁,max. Python's = assigns a value; == compares two values. In SciPy's SLSQP dictionary constraints, an equality callback returns zero, whereas an inequality callback must return a nonnegative value (≥ 0).

يفرض قيد المساواة المعادلة h(x) = 0، بينما يعبّر قيد عدم المساواة عن مجال مسموح مثل P₁ ≤ P₁,max. الرمز = في Python للإسناد و== للمقارنة. في قيود SciPy بطريقة SLSQP يجب أن تعيد دالة المساواة صفراً، وأن تعيد دالة عدم المساواة قيمة غير سالبة (≥ 0).

Mathematical model | النموذج الرياضي

Balance: h(P) = P₁ + P₂ − D = 0. Capacity: g(P) = P₁ − P₁,max ≤ 0. SciPy equivalent: c(P) = P₁,max − P₁ ≥ 0. Both expressions describe the same limit.

التوازن: h(P) = P₁ + P₂ − D = 0. السعة: g(P) = P₁ − P₁,max ≤ 0. والصياغة المكافئة في SciPy هي c(P) = P₁,max − P₁ ≥ 0؛ كلاهما يعبّر عن القيد نفسه.

Python · Kaggle · 02
demand_kw = 10.0
p1_max_kw = 6.0
def balance(x):
    return x[0] + x[1] - demand_kw
def capacity_margin(x):
    return p1_max_kw - x[0]
x = [6.0, 4.0]
print('h =', balance(x))
print('c =', capacity_margin(x))
print('Equal?', balance(x) == 0.0)

03

Degrees of freedom: zero or positive?

درجات الحرية: معدومة أم أكبر من الصفر؟

For a linear model with n independent decision variables and an equality matrix A, the equality-based degrees of freedom are DOF = n − rank(A), assuming consistency. Rank counts independent equations, not repeated rows. For a regular nonlinear system, use the local Jacobian rank. Inequality constraints and variable bounds may further restrict feasible directions, especially at active limits.

في نموذج خطي يحوي n متغيرات قرار مستقلة ومصفوفة معادلات مساواة A فإن درجة الحرية بالنسبة للمساواة هي DOF = n − rank(A) بشرط اتساق المعادلات. الرتبة تحصي المعادلات المستقلة لا الصفوف المكررة. وفي المسائل غير الخطية المنتظمة نستخدم رتبة مصفوفة المشتقات المحلية (Jacobian). ويمكن لقيود عدم المساواة وحدود المتغيرات أن تقيّد اتجاهات الحركة الممكنة، ولا سيما عند الحدود الفعّالة.

Mathematical model | النموذج الرياضي

Example A: two unknowns + independent equations P₁+P₂=10, P₁=6 → DOF = 2−2 = 0. Example B: only P₁+P₂=10 → DOF = 2−1 = 1. Duplicating this balance as 2P₁+2P₂=20 does not add an independent equation.

المثال A: مجهولان ومعادلتان مستقلتان P₁+P₂=10 وP₁=6 ⟵ DOF = 2−2 = 0. المثال B: المساواة الوحيدة P₁+P₂=10 ⟵ DOF = 2−1 = 1. وتكرارها بصيغة 2P₁+2P₂=20 لا يولّد معادلة مستقلة.

Python · Kaggle · 03
import numpy as np
a_zero = np.array([[1, 1], [1, 0]])
a_free = np.array([[1, 1]])
a_repeat = np.array([[1, 1], [2, 2]])
for title, a in [('zero', a_zero), ('free', a_free), ('repeat', a_repeat)]:
    n = a.shape[1]
    rank = np.linalg.matrix_rank(a)
    print(title, 'DOF =', n - rank)

04

How to organize an optimization program

الترتيب المنهجي لبرنامج الحل الأمثل

Separate the program into (1) imports, (2) fixed parameters and units, (3) decision vector, (4) derived physical relationships, (5) objective function, (6) equality constraints, (7) inequality constraints and bounds, (8) solver and settings, (9) feasibility validation, and (10) reporting. Do not change the physical model silently when changing an objective.

يُرتَّب البرنامج إلى: 1) استيراد المكتبات، 2) البارامترات الثابتة ووحداتها، 3) شعاع متغيرات القرار، 4) العلاقات الفيزيائية التابعة، 5) دالة الهدف، 6) معادلات المساواة، 7) قيود عدم المساواة وحدود المتغيرات، 8) المحلّل العددي وإعداداته، 9) التحقق من صلاحية الحل، 10) عرض النتائج. ولا يجوز تغيير النموذج الفيزيائي بصمت عند تعديل دالة الهدف.

Mathematical model | النموذج الرياضي

In a PV example, decide P_PV; derive P_grid = P_load − P_PV; then evaluate monetary cost C = tariff × P_grid × Δt. If P_grid is separately optimized, add the independent balance equation.

في مثال الطاقة الشمسية نختار P_PV متغير قرار، ثم نحسب P_grid = P_load − P_PV علاقة تابعة، وبعدها C = التعرفة × P_grid × Δt. إذا أضفنا P_grid متغير قرار مستقلاً، فيلزم فرض معادلة التوازن.

Python · Kaggle · 04
# 1: Parameters / البارامترات
data = {'load_kw': 10.0, 'tariff': 0.25}
# 2: Derived physical relation / العلاقة الفيزيائية
def grid_power(pv_kw, parameters):
    return parameters['load_kw'] - pv_kw
# 3: Objective / تابع الهدف
def cost(pv_kw, parameters):
    return parameters['tariff'] * grid_power(pv_kw, parameters)
# 4: Trial decision / قيمة قرار تجريبية
pv_kw = 4.0
print('Grid =', grid_power(pv_kw, data), 'kW')
print('Cost for 1h =', cost(pv_kw, data))

05

Zero degrees of freedom: solve the equations

درجة حرية معدومة: حل المعادلات دون أمثلية

When independent equalities uniquely fix all decision variables and their solution respects bounds, there is no remaining freedom to optimize. First solve the equations; optimization cannot improve the only feasible point. Here P₁ + P₂ = 10 and P₁ = 6 determine P₂ = 4.

إذا حددت معادلات المساواة المستقلة كل متغيرات القرار تحديداً وحيداً وكان الحل ضمن الحدود، فلا تبقى حرية للمفاضلة. نحل المعادلات أولاً؛ إذ لا يمكن للأمثلية تحسين نقطة ممكنة وحيدة. هنا P₁ + P₂ = 10 وP₁ = 6 تحددان P₂ = 4.

Mathematical model | النموذج الرياضي

A x = b with A = [[1, 1], [1, 0]] and b = [10, 6]. Rank(A) = 2, number of unknowns = 2, DOF = 0. Unique solution (P₁,P₂) = (6,4) kW.

نحل A x = b، حيث A = [[1,1],[1,0]] وb = [10,6]. رتبة A هي 2 وعدد المجهولات 2، فتكون DOF = 0، والحل الوحيد (P₁,P₂) = (6,4) كيلوواط.

Python · Kaggle · 05
import numpy as np
# Coefficients for two independent equations
A = np.array([[1, 1], [1, 0]], dtype=float)
b = np.array([10.0, 6.0])
powers = np.linalg.solve(A, b)
print('P1 =', round(powers[0], 2), 'kW')
print('P2 =', round(powers[1], 2), 'kW')
print('DOF =', A.shape[1] - np.linalg.matrix_rank(A))

One decision variable: minimize grid import cost

Mathematical model | النموذج الرياضي

from scipy.optimize import minimize
load_kw = 6.0
pv_max_kw = 4.0
tariff_per_kwh = 0.25
hours = 1.0
def grid_cost(x):
    pv_kw = x[0]
    grid_kw = load_kw - pv_kw
    return tariff_per_kwh * grid_kw * hours
upper = min(load_kw, pv_max_kw)
solution = minimize(grid_cost, x0=[1.0], bounds=[(0.0, upper)], method='SLSQP')
if not solution.success:
    raise RuntimeError(solution.message)
pv_kw = float(solution.x[0])
print('PV =', round(pv_kw, 3), 'kW')
print('Grid =', round(load_kw - pv_kw, 3), 'kW')
print('Cost =', round(solution.fun, 3))

Maximum versus minimum objectives

مسألة عظمى ومسألة دنيا: كيف نغيّر تابع الهدف؟

SciPy minimize solves a minimum. To solve max B(x), minimize −B(x) over exactly the same feasible set. A maximization is not written by changing equality or inequality directions. Example: illustrative benefit B(p)=0.5p−0.1p² on 0≤p≤4; its interior maximum is p*=2.5, not always at a bound.

تحل minimize مسألة تصغير. ولحل max B(x) نصغّر −B(x) ضمن مجموعة الحلول الممكنة نفسها. لا نحوّل مسألة العظمى إلى دنيا بقلب إشارات قيود المساواة أو عدم المساواة. مثال تعليمي للمنفعة B(p)=0.5p−0.1p² على المجال 0≤p≤4؛ تحقق العظمى الداخلية عند p*=2.5، وليس دائماً على الحدود.

Mathematical model | النموذج الرياضي

max 0.5p−0.1p² ↔ min −(0.5p−0.1p²), subject to 0≤p≤4. Stationary point: dB/dp=0.5−0.2p=0 → p=2.5. Max B=0.625 arbitrary benefit units.

max (0.5p−0.1p²) تكافئ min −(0.5p−0.1p²) بشرط 0≤p≤4. من الاشتقاق dB/dp=0.5−0.2p=0 نجد p=2.5، والعظمى B=0.625 وحدة منفعة افتراضية.

    raise RuntimeError(result.message)

print('Maximum benefit =', round(benefit(p_star), 3))

Clean, reusable optimization program

Python · Kaggle · 10
from scipy.optimize import minimize
# 1. PARAMETERS / البارامترات
DATA = {'demand': 10.0, 'a1': 1.0, 'a2': 2.0,
        'p1_max': 6.0, 'p2_max': 8.0}
# 2. OBJECTIVE / تابع الهدف
def objective(x):
    p1, p2 = x
    return DATA['a1'] * p1**2 + DATA['a2'] * p2**2
# 3. EQUALITY / قيد المساواة
def balance(x):
    return x[0] + x[1] - DATA['demand']
# 4. SOLVE / الحل العددي
def solve():
    capacity = DATA['p1_max'] + DATA['p2_max']
    if DATA['demand'] > capacity:
        raise ValueError('Demand exceeds total capacity')
    bounds = [(0.0, DATA['p1_max']), (0.0, DATA['p2_max'])]
    rules = [{'type': 'eq', 'fun': balance}]
    return minimize(objective, [5.0, 5.0], method='SLSQP',
                    bounds=bounds, constraints=rules)
# 5. VALIDATE AND REPORT / التحقق وعرض النتائج
def main():
    result = solve()
    if not result.success or abs(balance(result.x)) > 1e-6:
        raise RuntimeError('Optimization result not verified')
    p1, p2 = result.x
    print('P1 =', round(p1, 3), 'kW')
    print('P2 =', round(p2, 3), 'kW')
    print('Cost =', round(result.fun, 3))
if __name__ == '__main__':
    main()

Professional checklist | قائمة المراجعة المهنية

Before accepting a result, ask: Is the chosen objective meaningful? Are units consistent? Are equality constraints independent and satisfied? Are inequalities and bounds respected? Is there sufficient total capacity? Did the solver converge? Is a limit active? Is the solution unique or might another optimum exist?

قبل قبول النتيجة اسأل: هل تابع الهدف مناسب؟ هل الوحدات متسقة؟ هل معادلات المساواة مستقلة ومحققة؟ هل تحققت قيود عدم المساواة والحدود؟ هل تكفي السعة الكلية؟ هل تقارب المحلّل؟ هل هناك حد فعال؟ هل الحل وحيد أم قد توجد حلول مثلى أخرى؟

In real power-system optimization, additional models may be required for losses, voltage, reactive power, ramps, efficiency, safety, and uncertainty. These teaching examples intentionally simplify the physics. Keep the mathematical formulation separate from the numerical method.

في أمثلية أنظمة الطاقة الواقعية قد نحتاج أيضاً إلى نمذجة الفواقد والتوترات والاستطاعة الردية ومعدلات التغير والكفاءة والسلامة وعدم اليقين. بُسّطت الفيزياء في هذه الأمثلة للتعليم. يجب فصل الصياغة الرياضية عن طريقة الحل العددي.
