What are rank and Jₕ? | ما معنى الرتبة ومصفوفة يعقوبي؟

rank is the number of linearly independent rows (equivalently, columns) in a matrix—not simply its row count. Jₕ is the Jacobian matrix of equality residual functions h(x). Each row describes one equality residual; each column corresponds to one decision variable. The entry in row i and column j is the partial derivative ∂hᵢ/∂xⱼ.

⁦rank (⁩الرتبة) هو عدد الصفوف المستقلة خطيا في المصفوفة (ويساوي عدد الأعمدة المستقلة)، وليس مجرد عدد صفوفها. أما ⁦J⁩ₕ فهي مصفوفة يعقوبي لتوابع بواقي معادلات المساواة ⁦h(x).⁩ يمثل كل صف تابع قيد مساواة، وكل عمود متغير قرار. والعنصر في الصف ⁦i⁩ والعمود ⁦j⁩ هو المشتقة الجزئية ⁦∂hᵢ/∂x⁩ⱼ.

Step 1 | الخطوة الأولى: معادلة توازن واحدة

With decision variables x=[P₁,P₂], define h₁=P₁+P₂−10. Its partial derivatives are ∂h₁/∂P₁=1 and ∂h₁/∂P₂=1. Thus Jₕ=[1,1], rank=1 and DOF=2−1=1. One power can vary and the other follows from the balance.

لدينا متغيرا القرار ⁦x = [P₁, P₂]⁩ والعلاقة ⁦h₁ = P₁ + P₂ − 10 = 0⁩. المشتقتان الجزئيتان هما ⁦∂h₁/∂P₁ = 1⁩ و⁦∂h₁/∂P₂ = 1⁩. إذن ⁦J⁩ₕ = [⁦1, 1]⁩ ورتبتها ⁦1⁩، فدرجة الحرية ⁦DOF = 2 − 1 = 1⁩. يمكن تغيير استطاعة أحد المولدين وتتحدد الأخرى بالتوازن.

Jₕ = [ 1 1 ]   →   rank(Jₕ) = 1   →   DOF = 1
Step 2 | الخطوة الثانية: إضافة معادلة مستقلة

Add h₂=P₁−6=0. The new row of derivatives is [1,0], independent of [1,1]. Hence Jₕ=[[1,1],[1,0]], rank=2 and DOF=0. The uniquely determined solution is P₁=6 kW and P₂=4 kW, provided it satisfies all bounds.

نضيف ⁦h₂ = P₁ − 6 = 0⁩. صف مشتقاتها [⁦1, 0]⁩ مستقل عن [⁦1, 1]⁩. إذن ⁦J⁩ₕ = [[⁦1, 1], [1, 0]]⁩ ورتبتها ⁦2⁩، فدرجة الحرية صفر. يكون الحل المحدد وحيدا ⁦P₁=6⁩ كيلوواط و⁦P₂=4⁩ كيلوواط بشرط احترام الحدود.

Jₕ = [ [1, 1], [1, 0] ]   →   rank(Jₕ) = 2   →   DOF = 0
Step 3 | الخطوة الثالثة: معادلة مكررة وليست مستقلة

Instead, adding 2P₁+2P₂=20 only duplicates the original balance: its derivative row [2,2] is twice [1,1]. So the matrix still has rank=1 and DOF=1, despite containing two rows.

أما إضافة ⁦2P₁ + 2P₂ = 20⁩ فهي تكرار لمعادلة التوازن نفسها؛ لأن صف مشتقاتها [⁦2, 2]⁩ يساوي ضعفي [⁦1, 1]⁩. لذلك تبقى الرتبة ⁦1⁩ ودرجة الحرية ⁦1⁩ رغم وجود صفين.

Jₕ = [ [1, 1], [2, 2] ]   →   rank(Jₕ) = 1   →   DOF = 1

Important: DOF = n − rank(Jₕ) describes the local dimension of the solution set for regular equality constraints. For consistent linear equations, use the coefficient matrix A directly. Nonlinear singular points require extra care. Inequality limits can restrict feasible directions even when equality-based DOF is positive. Python: np.linalg.matrix_rank(A).

مهم: تصف ⁦DOF = n − rank(J⁩ₕ) البعد المحلي لمجموعة الحلول عند انتظام قيود المساواة. وفي المعادلات الخطية المتسقة نستخدم مصفوفة المعاملات ⁦A⁩ مباشرة. أما النقاط الشاذة في الأنظمة غير الخطية فتحتاج دراسة إضافية. قد تقيد حدود عدم المساواة الحركة الممكنة حتى عندما تكون درجة الحرية بالنسبة للمساواة موجبة. نستخدم في ⁦Python⁩ التعليمة np.linalg.matrix_rank(A).

Mathematical Function vs. Mathematical Relation | التابع الرياضي مقابل العلاقة الرياضية

First definition | التعريف الأول للطلاب

Function: every permitted x has exactly one y. Relation: the same x may have no y, one y, or several y values (depending on the stated domain). Every function is a relation, but not every relation is a function.

التابع الرياضي: لكل قيمة ⁦x⁩ في مجال تعريفه قيمة وحيدة فقط لـ ⁦y.⁩ العلاقة الرياضية: قد تقابل قيمة ⁦x⁩ أي قيمة لـ ⁦y⁩ أو قيمة واحدة أو أكثر من قيمة، بحسب المجال المدروس. كل تابع هو علاقة، ولكن ليست كل علاقة تابعا.

Function: y=2x+1 gives one y for each x. Relation: x²+y²=1 gives y=+1 and y=−1 at x=0; it is not a single-valued function y(x) for the full circle.

مثال تابع: ⁦y=2x+1⁩ يعطي قيمة ⁦y⁩ وحيدة لكل ⁦x.⁩ مثال علاقة: ⁦x²+y²=1⁩ يعطي ⁦y=+1⁩ و⁦y=−1⁩ عند ⁦x=0⁩، ولذلك لا يمثل تابعا وحيد القيمة ⁦y(x)⁩ على كامل الدائرة.

Mathematical function: a mapping f:A→B assigning exactly one output f(a) for every input a in its domain A. A function may have multiple inputs, for example P(V,I)=V×I. Two different inputs may give the same result.

التابع الرياضي: تطبيق ⁦f:A→B⁩ يربط كل مدخل ⁦a⁩ من مجال التعريف ⁦A⁩ بخرج واحد فقط ⁦f(a).⁩ وقد يقبل التابع عدة مدخلات مثل ⁦P(V,I)=V×I⁩، كما قد يعطي مدخلان مختلفان النتيجة نفسها.

Mathematical relation: a set of allowed tuples or a condition (equality, inequality, etc.) connecting quantities. It is not required to yield a unique output. The circle x²+y²=1 permits y=+1 and y=−1 at x=0; therefore the complete circle is not a single-valued function y(x).

العلاقة الرياضية: مجموعة من التركيبات المسموحة أو شرط (مساواة أو عدم مساواة وغيرها) يربط الكميات. ليس ضروريا أن تعطي خرجا وحيدا. فالدائرة ⁦x²+y²=1⁩ تسمح بقيمتي ⁦y=+1⁩ و⁦y=−1⁩ عندما ⁦x=0⁩؛ لذلك ليست الدائرة كاملة تابعا وحيد القيمة ⁦y(x).⁩

Core distinction | التمييز الجوهري

Every mathematical function is a special type of mathematical relation, but not every relation is a single-valued function. In optimization, f(x) is an objective function; h(x)=0 and g(x)≤0 are constraint relations formed using residual functions h and g. The formal arguments of Python's def are not necessarily fixed model parameters.

كل تابع رياضي نوع خاص من العلاقات الرياضية، لكن ليست كل علاقة تابعا وحيد القيمة. في الأمثلية يكون ⁦f(x)⁩ تابع الهدف؛ أما ⁦h(x)=0⁩ و⁦g(x)≤0⁩ فهما علاقتا قيد تتكونان باستعمال تابعي الباقي ⁦h⁩ و⁦g.⁩ ووسائط التابع البرمجي ⁦def⁩ ليست بالضرورة بارامترات ثابتة للنموذج.

The language of a mathematical model

لغة النموذج الرياضي: المتغيرات والبارامترات والتوابع والعلاقات

A decision variable is selected by the solver; a model parameter stays fixed during one solve. Function: each x in its domain gives exactly one y. Relation: an x may correspond to zero, one or several y values. A relation can sometimes be rearranged as an explicit function. Python def defines an implementation of a computation.

متغير القرار يختاره المحلل، وبارامتر النموذج يبقى ثابتا خلال الحل الواحد. التابع: لكل ⁦x⁩ في مجال تعريفه قيمة ⁦y⁩ وحيدة. العلاقة: قد تقابل ⁦x⁩ صفر أو قيمة واحدة أو عدة قيم لـ ⁦y.⁩ وقد يمكن إعادة صياغة العلاقة كتابع صريح. أما def في ⁦Python⁩ فتعرف تابعا برمجيا لتنفيذ الحساب.

Mathematical model | النموذج الرياضي

Physical equality relation (Ohm’s law): V−RI=0. When R>0, this relation uniquely determines the explicit mathematical function I(V,R)=V/R. With fixed parameters V=12 V and R=6 Ω, I=2 A. We verify the equality by computing its residual V−RI=0.

علاقة المساواة الفيزيائية (قانون أوم): ⁦V−RI=0.⁩ عندما ⁦R>0⁩ تحدد العلاقة تابعا رياضيا صريحا ⁦I(V,R)=V/R⁩ يعطي تيارا وحيدا. إذا كانت البارامترات ⁦V=12 V⁩ و⁦R=6 Ω⁩ فالتيار ⁦I=2 A.⁩ نتحقق من العلاقة بحساب باقي المساواة ⁦V−RI=0.⁩

Equality, inequality and Python symbols

المساواة وعدم المساواة ورموز ⁦Python⁩

An equality constraint is a mathematical relation h(x)=0, in which h is a numerical residual function. An inequality constraint is another relation g(x)≤0, in which g is a numerical function. Functions calculate values; relations restrict the feasible set. Python = means assignment, while == means comparison. Degrees of freedom: zero or positive?

درجات الحرية: معدومة أم أكبر من الصفر؟

For a linear model with n independent decision variables and an equality matrix A, the equality-based degrees of freedom are DOF = n − rank(A), assuming consistency. Rank counts independent equations, not repeated rows. For a regular nonlinear system, use the local Jacobian rank. Inequality constraints and variable bounds may further restrict feasible directions, especially at active limits.

في نموذج خطي يحوي ⁦n⁩ متغيرات قرار مستقلة ومصفوفة معادلات مساواة ⁦A⁩ فإن درجة الحرية بالنسبة للمساواة هي ⁦DOF = n − rank(A)⁩ بشرط اتساق المعادلات. الرتبة تحصي المعادلات المستقلة لا الصفوف المكررة. وفي المسائل غير الخطية المنتظمة نستخدم رتبة مصفوفة المشتقات المحلية (⁦Jacobian).⁩ ويمكن لقيود عدم المساواة وحدود المتغيرات أن تقيد اتجاهات الحركة الممكنة، ولا سيما عند الحدود الفعالة.

Two-generator economic dispatch with an equality

bounds = [(0.0, 6.0), (0.0, 8.0)]
def total_cost(x):
    p1, p2 = x
    return a1 * p1**2 + a2 * p2**2
def power_balance(x):
    return x[0] + x[1] - demand_kw
constraints = [{'type': 'eq', 'fun': power_balance}]
result = minimize(total_cost, x0=[5.0, 5.0], method='SLSQP',
                  bounds=bounds, constraints=constraints)
if not result.success:
    raise RuntimeError(result.message)
p1, p2 = result.x
print('P1, P2 =', round(p1, 3), round(p2, 3))
print('Minimum cost =', round(result.fun, 3))
print('Balance residual =', round(power_balance(result.x), 8))

Maximum versus minimum objectives

مسألة عظمى ومسألة دنيا: كيف نغير تابع الهدف؟

SciPy minimize solves a minimum. To solve max B(x), minimize −B(x) over exactly the same feasible set. A maximization is not written by changing equality or inequality directions. Example: illustrative benefit B(p)=0.5p−0.1p² on 0≤p≤4; its interior maximum is p*=2.5, not always at a bound.

تحل ⁦minimize⁩ مسألة تصغير. ولحل ⁦max B(x)⁩ نصغر ⁦−B(x)⁩ ضمن مجموعة الحلول الممكنة نفسها. لا نحول مسألة العظمى إلى دنيا بقلب إشارات قيود المساواة أو عدم المساواة. مثال تعليمي للمنفعة ⁦B(p)=0.5p−0.1p²⁩ على المجال ⁦0≤p≤4⁩؛ تحقق العظمى الداخلية عند ⁦p*=2.5⁩، وليس دائما على الحدود.

from scipy.optimize import minimize
# 1. PARAMETERS / البارامترات
DATA = {'demand': 10.0, 'a1': 1.0, 'a2': 2.0,
        'p1_max': 6.0, 'p2_max': 8.0}
# 2. OBJECTIVE / تابع الهدف
def objective(x):
    p1, p2 = x
    return DATA['a1'] * p1**2 + DATA['a2'] * p2**2
# 3. EQUALITY / قيد المساواة
def balance(x):
    return x[0] + x[1] - DATA['demand']
# 4. SOLVE / الحل العددي
def solve():
    capacity = DATA['p1_max'] + DATA['p2_max']
    if DATA['demand'] > capacity:
        raise ValueError('Demand exceeds total capacity')
    bounds = [(0.0, DATA['p1_max']), (0.0, DATA['p2_max'])]
    rules = [{'type': 'eq', 'fun': balance}]
    return minimize(objective, [5.0, 5.0], method='SLSQP',
                    bounds=bounds, constraints=rules)
# 5. VALIDATE AND REPORT / التحقق وعرض النتائج
def main():
    result = solve()
    if not result.success or abs(balance(result.x)) > 1e-6:
        raise RuntimeError('Optimization result not verified')
    p1, p2 = result.x
    print('P1 =', round(p1, 3), 'kW')
    print('P2 =', round(p2, 3), 'kW')
    print('Cost =', round(result.fun, 3))
if __name__ == '__main__':
    main()

        choices = []
        for new in states:
            grid = 1+new-old
            if grid >= 0 and abs(new-old) <= 1:
                choices.append((prices[t]*grid+J[new], new))
        value, new = min(choices)
        current[old] = value
        policy[t, old] = new
    J = current
assert J[0] == 2 and policy[0,0] == 1
print('Minimum cost=', J[0], 'CU; charge then discharge')

from scipy.optimize import linprog
for prob in [0.5, 0.2]:
    # Variables [q,r_low,r_high]; q+r_low >= 4
    r = linprog([2,5*prob,5*(1-prob)],

Complexity, solver selection and comparison

التعقيد واختيار المحللات ومقارنة النتائج

A model class does not determine an exact running time. Compare mathematical structure, size, precision and optimality guarantees. The code below uses free solver packages and solves the same models already calculated by hand.

لا يحدد نوع النموذج زمن تشغيل دقيقا. نقارن البنية والحجم والدقة وضمانات الأمثلية. يستخدم الكود التالي محللات مجانية لحل النماذج نفسها المحسوبة يدويا.

Convexity: the straight segment between any two feasible points stays feasible; for a convex minimization objective, every local minimum is global. With linear constraints, a QP is convex when its quadratic matrix is positive semidefinite. Convex does not mean linear.

التحدب: تبقى القطعة المستقيمة بين أي نقطتين ممكنتين داخل المجموعة الممكنة؛ ومع هدف تصغير محدب يكون كل أدنى محلي أدنى عالميا. ومع قيود خطية تكون المسألة التربيعية محدبة عندما تكون مصفوفتها التربيعية موجبة شبه محددة. التحدب لا يعني الخطية.

Complexity: polynomial growth, such as n² or n³, differs from exponential growth such as 2ⁿ. These are operation-count illustrations, not exact bounds for every solver. For LP, theoretical polynomial bounds account for input encoding length. NP-hard means at least as hard as every problem in NP under polynomial reductions; no general polynomial-time exact algorithm is known. It does not mean every instance is slow or unsolvable.

التعقيد: يختلف النمو متعدد الحدود مثل مربع الحجم أو مكعبه عن النمو الأسي مثل 2 مرفوعة لعدد القرارات. هذه أمثلة لعدد العمليات وليست حدودا دقيقة لكل محلل. تراعي الحدود النظرية للبرمجة الخطية طول تمثيل بيانات المسألة. وتعني الصعوبة من فئة NP-hard أن كل مسألة في NP يمكن تحويلها إليها خلال زمن متعدد الحدود؛ ولا تعرف خوارزمية عامة دقيقة متعددة الحدود لحلها. لا يعني ذلك أن كل مثال بطيء أو غير قابل للحل.
