Engineering problem | المسألة الهندسية

A 20 kV single-phase source supplies Z = 30 + jX Ω. Start with X=15 Ω, then study X=5…20 Ω.

يغذي مصدر أحادي الطور بجهد 20 kV حملاً ممانعته Z=30+jX Ω. نبدأ عند X=15 Ω ثم ندرس المجال X=5…20 Ω.
I(X)=V/(R+jX)
قبل البرمجة: احسب تقريباً |I| عند X=15 Ω وتوقع ماذا يحدث للتيار عندما تزداد X.

Task A · MATLAB | المهمة A

V = 20e3;
R = 30;
X = 15;
Z = R + 1j*X;
I = V/Z;

fprintf('|I| = %.2f A\n',abs(I));
fprintf('angle(I) = %.2f deg\n',angle(I)*180/pi);

Verify that |I| ≈ 596.3 A and explain the sign of the current angle.

تحقق من أن |I|≈596.3 A واشرح هندسياً إشارة زاوية التيار.

Task B · Sweep X | المهمة B: تغيير X

X = 5:20;
Iabs = zeros(size(X));

for k = 1:length(X)
    Z = R + 1j*X(k);
    Iabs(k) = abs(V/Z);
end

plot(X,Iabs,'o-'); grid on
xlabel('X (ohm)')
ylabel('|I| (A)')

Challenge: rewrite the calculation using vectorized MATLAB operations.

تحدٍ: أعد كتابة الحساب باستخدام العمليات المتجهية في MATLAB بدلاً من الحلقة.

Task E · Complex power | المهمة E: الاستطاعة العقدية

% MATLAB
X = 15;
Z = R + 1j*X;
I = V/Z;
S = V*conj(I);
P = real(S);
Q = imag(S);
pf = P/abs(S);

سجل P بالـMW وQ بالـMVAr وpf. ثم تحقق من P≈|I|²R وQ≈|I|²X. اشرح لماذا Q موجبة في هذه الحالة.

Task F · Function building | المهمة F: بناء دالة

function [I,S,pf] = analyze_load(V,R,X)
    Z = R + 1j*X;
    I = V/Z;
    S = V*conj(I);
    pf = real(S)/abs(S);
end

شغّل الدالة للحالات X=5، 15، 20 Ω وأنشئ جدولاً صغيراً يحوي X و|I| وP وQ وpf. هذه الخطوة تربط الدوال التي درسها الطالب سابقاً بمهمة هندسية قابلة لإعادة الاستخدام.
