Your First Power-Engineering Notebook

أول Notebook في هندسة الطاقة
90 min | 90 دقيقةPhone + KagglePython

Lab goal | هدف المخبر

By the end, every student should have a saved Kaggle Notebook created and executed from a phone, containing Markdown, Python calculations, a NumPy parameter sweep and a Matplotlib figure.

بنهاية المخبر يجب أن يمتلك كل طالب Kaggle Notebook محفوظاً أنشأه وشغّله من الهاتف، ويحتوي على Markdown وحسابات Python ومسح قيم باستخدام NumPy ورسم باستخدام Matplotlib.

90-minute workflow | خطة 90 دقيقة

0–10: Open/rename Notebook and interface check.
فتح Notebook وتسميته والتأكد من الواجهة.

10–25: Code and Markdown cells.
خلايا Code وMarkdown.

25–40: Python variables and MATLAB translation.
المتغيرات وترجمة مثال من MATLAB إلى Python.

40–60: Complex load calculation and NumPy sweep.
حساب حمل عقدي ومسح قيم باستخدام NumPy.

60–75: Plot and interpretation.
الرسم والتفسير الهندسي.

75–83: Debugging + ChatGPT.
اكتشاف الأخطاء والاستفادة من ChatGPT.

83–90: Save, submit/check and exit quiz.
الحفظ والتحقق والاختبار الختامي.

📱 STEP 1

Open and prepare Kaggle | افتح Kaggle وجهّز العمل

Open Kaggle Code → New Notebook → rename it PE2_L01_YourName.

افتح Kaggle Code ← اختر New Notebook ← غيّر الاسم إلى PE2_L01_YourName. أبقِ صفحة المخبر في تبويب وKaggle في تبويب آخر.

Task 1 · Markdown cell | المهمة 1 · خلية Markdown

Add a Markdown cell with the course, lab, your name, and the objective: “Study current versus load reactance.”

أضف خلية Markdown تتضمن اسم المقرر والمخبر واسمك والهدف: «دراسة تغير التيار مع مفاعلة الحمل».

Task 2 · First Python cell | المهمة 2 · أول خلية Python

print("Programming in Electrical Power II")
V = 20e3
R = 30
X = 15
print(V, R, X)

Run the cell. Change X once and run it again. Observe that a variable can be reassigned without rewriting the Notebook.

شغّل الخلية، ثم غيّر X مرة واحدة وأعد التشغيل. لاحظ أن قيمة المتغير يمكن تغييرها دون إعادة كتابة الـNotebook.

Task 3 · Translate from MATLAB | المهمة 3 · الانتقال من MATLAB

MATLAB you already know:

الصيغة التي تعرفها مسبقاً في MATLAB:
V = 20e3;
Z = 30 + 1j*15;
I = V/Z;
abs(I)

Now write/run the Python equivalent:

الآن اكتب وشغّل الصيغة المقابلة في Python:
import numpy as np
V = 20e3
Z = 30 + 1j*15
I = V/Z
print(abs(I))
print(np.angle(I, deg=True))

Record |I| and its angle. Explain why the angle is negative.

سجّل مطال التيار وزاويته، واشرح لماذا زاوية التيار سالبة.

Task 4 · NumPy array | المهمة 4 · مصفوفة NumPy

R = 30
X = np.arange(5, 21)
Z = R + 1j*X
I = V/Z

print(X)
print(np.abs(I))

Identify the current at X=5, 15 and 20 Ω. Predict the trend before reading all values.

حدد قيمة التيار عند X=5 و15 و20 Ω. توقّع اتجاه تغير التيار قبل قراءة جميع القيم.

Task 5 · First engineering plot | المهمة 5 · أول رسم هندسي

import matplotlib.pyplot as plt

plt.plot(X, np.abs(I), marker="o")
plt.xlabel("Reactance X (ohm)")
plt.ylabel("Current magnitude |I| (A)")
plt.title("Current versus load reactance")
plt.grid(True)
plt.show()

Write two observations below the plot in a Markdown cell.

اكتب ملاحظتين هندسيتين تحت الرسم في خلية Markdown: اتجاه المنحني، والسبب الفيزيائي لهذا الاتجاه.

Task 6 · Small independent change | المهمة 6 · تعديل مستقل صغير

Change R from 30 Ω to 20 Ω. Before running, predict the effect on |I|. Run and compare.

غيّر R من 30 Ω إلى 20 Ω. قبل التشغيل توقّع تأثير ذلك في |I|، ثم شغّل الخلية وقارن النتيجة بتوقعك.

Task 7 · Debugging | المهمة 7 · اكتشاف الأخطاء

V = 20000
R = 30
X = 15
Z = R + X
I = V * Z
print(I)

The code runs, but the engineering model is wrong. Find two conceptual errors before asking AI.

الكود يعمل، لكن النموذج الهندسي خاطئ. اكتشف خطأين مفاهيميين قبل استخدام الذكاء الاصطناعي.
“The code runs but should model Z=R+jX and I=V/Z. Explain what is conceptually wrong without writing the full corrected code.”
«الكود يعمل لكنه يجب أن يمثل Z=R+jX وI=V/Z. اشرح الأخطاء المفاهيمية دون كتابة الكود المصحح كاملاً.»

Required Notebook | الـNotebook المطلوب

Your saved file must contain: title/identity Markdown, scalar calculation, complex current, NumPy X sweep, one labeled plot, two engineering observations, and the corrected debugging cell.

يجب أن يحتوي الملف المحفوظ على: عنوان وبيانات الطالب في Markdown، حساب عددي بسيط، التيار العقدي، مسح X باستخدام NumPy، رسم بمحاور ووحدات، ملاحظتين هندسيتين، وخلية اكتشاف الأخطاء بعد تصحيحها.
